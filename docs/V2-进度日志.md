## PORTRAIT 精修: 透明塑封围边 + 环境色过渡 + 层次 ✅ 2026-09-16
**用户要求**: 边框要有"透明塑封的围边感、明亮透明";边框色**从照片环境取色**,并让照片到边框有**轻微过渡渐变**;照片要**有层次**。

**实现(`dl2/design.py` 的 PORTRAIT 渲染)**
| 要素 | 做法 |
|---|---|
| **围边底色** | 新增 `edge_env_color()`:取照片四边各 26px 的平均色 → 去饱和 35% → **提亮 40%** → 得到明亮通透的"卡纸+塑封"底色;再叠**竖向微渐变**(上略亮/下略深) |
| **过渡渐变** | 新增 `feathered_mask()`:照片四边各 **16px 线性羽化**,贴到围边上时自然融进去(不是硬切边) |
| **塑封反光** | 整卡斜向宽光泽 + 一条**窄高光带**(模拟塑料反光);内外各两条细亮线(塑封与照片交界 + 卡外缘) |
| **层次感** | ① 照片内侧一圈**柔和内阴影**(像压在塑封下)②**上缘额外投影**(光从上方来)③ 新增 `clarity()` 局部对比(USM r34/26%)④ 原有暗角保留 |

**实测**:`04-sea-dress` 成图放大 0.8×(清晰,无告警);演示卡 `card-portrait01` 的正面/static/预览/查看器资源已同步更新。

## 修复: 材质"只有金/普通两种"+ 工作台无法调材质 ✅ 2026-09-16

2. **四档差异不足**: pearl 与 silver 都是同一条 `spectrum()` 彩虹, silver 仅去饱和 → 看起来几乎一样
3. **V2 模式下没有材质入口**: 材质/景深面板在旧的「② 卡片信息」里, 而它已随旧模板移入「经典模板」模式被隐藏

**改动**
- **Shader 拉开四档**(`app.js` → 已同步 49 个查看器并重建 bundle)
  - 珠光: 高饱和彩虹色带(带独立色带调制)
  - 银: 冷色金属 + 竖向亮线(不再"灰色彩虹")
  - 原色: 无薄膜(不变)
  - 金: 暖金分带(不变)
  - 静止存在感 0.15 → **0.22**(仍属克制, 但正视即可分辨材质); 分区珠光幅度 .17 → .26
- **V2 工作台新增「④ 精修」面板**: 表面光泽(珠光/银/原色/金) + 材质组合 5 档 + 景深 4 滑杆 +
  「应用到 3D 预览」→ 写配置并**自动重载预览**(不必新窗口)
- **V2 卡的配置编辑路径**(`apply_config_edits.py`): 文本变化才按 `designLanguage` 重出(dl2/build_card.py);
  只改外观参数则**只更新配置**(秒回, 不误触发旧模板渲染器)
- **`make_static_card` 支持 V2 fallback**: 无 `assets/background.png` 时用 `assets/front.png`(规范 fallback),
  修掉"应用材质返回 500"的问题

## 修复: 3D 拖动时被自动切回「正面静帧」 ✅ 2026-09-16
**现象**: 在 3D 里拖动卡片, 隔一会儿画面自己切回正面静帧。
**根因**: `showView` 里我加的"**8 秒 3D 就绪检测**"——超时就**自动切到静态图**当回退。
但 DOM 兜底路径下 `window.__holo.ready` 未必暴露, 且 V2 卡首屏要加载大贴图(background 2.5MB 等),
8 秒经常不够 → 于是**每次都被切走**。

**改动(`public/index.html`)**
- **删除"自动切模式"**: 用户选定的模式不再被程序改掉
- 就绪判定放宽为多信号: `__holo.ready` **或** 页面已出现 `canvas / .flipper3d / .layer3d` **或** `readyState !== "complete"`(仍在加载)
- 检测窗口 ~24 秒(2.5s 起, 每 2s 一次, 共 12 次), 期间只显示底部提示
- 真失败时才提示"3D 页面报错: 可点 ↗ 在新窗口打开查看原因", **仍不切模式**

**验证**: 界面脚本 `node --check` 通过;代码中已不存在 `viewMode = "static"` + `showView(id,"static")` 的组合 ✓

**已知问题**: 若 3D 确实加载失败(而非慢), 现在会安静地留在 3D 视图 — 需要用户反馈"看到了什么"(空白/报错文字)才能继续定位;
V2 卡首屏贴图较大(合计约 5MB), 后续可考虑出 webp 或降采样以加快首屏。
