# 让「一个码只能导入一次」真正生效：五步

> 这份是给你（不写代码的人）看的操作单。每一步做完都有"怎么确认我做对了"。

## 第 0 步：先搞清楚现在能看什么

小程序现在跑在 **本地演示模式**（`miniprogram/config.js` 里 `mode: 'mock'`）。这个模式：

- ✅ 能完整走一遍：**输入码 → 卡片出现 → 再输一次 → 提示"已被领取"**
- ❌ **防不住转发**：登记处就在这台手机里，换一台手机就是新的登记处

所以它只用来**看效果**。要让"一个码只能被一个人领"真正成立，必须有一个**共用的登记处**——就是你选的微信云开发。

## 第 1 步：注册小程序，拿到 AppID（免费，约 10 分钟）

1. 打开 <https://mp.weixin.qq.com/> → 右上角「立即注册」→ 选「**小程序**」
2. 用一个**没注册过公众号/小程序的邮箱**注册 → 主体类型选「**个人**」→ 身份证 + 微信扫码验证
3. 注册完成后，进后台「**设置 → 基本设置**」，找到 **AppID**（形如 `wx1234567890abcdef`）

> ⚠️ **不要用测试号**。官方明确：测试号的 AppID 用不了云开发（会提示"请输入正式的 appid"）。
>
> 个人主体免费，且**个人主体可以使用云开发**。如果注册过程中遇到需要"认证/付费"的页面，先停下来问我。

**怎么确认做对了**：你手里有一串 `wx` 开头的 AppID。

## 第 2 步：把 AppID 填进项目

打开 `miniprogram/project.config.json`，把这一行换掉：

```json
"appid": "touristappid"      →      "appid": "你的 AppID"
```

## 第 3 步：开通云开发，拿到环境 ID

1. 用「微信开发者工具」打开 `miniprogram` 目录 → 点顶部工具栏的「**云开发**」
2. 按提示开通（选**按量付费**即可，有免费额度，个人用几乎不会产生费用）
3. 开通后进「云开发控制台 → **设置 → 环境**」，复制**环境 ID**（形如 `cloud1-9gxxxxxx`）
4. 打开 `miniprogram/config.js`，改成：

```js
mode: 'cloud',                    // 从 'mock' 改成 'cloud'
cloudEnv: 'cloud1-9gxxxxxx',      // 填你复制的环境 ID
```

**怎么确认做对了**：小程序打开后收藏页是空态（不再是演示码提示），说明它已经在等云开发返回数据。

## 第 4 步：建数据库集合 + 部署两个云函数

1. 云开发控制台 →「**数据库**」→ 新建集合，名字**必须**叫 `cards`
   - 权限选「**所有用户不可读写**」（读写都走云函数，这样最安全）
   - 建议再建一个索引：字段 `code`，设为**唯一**（防止重复码）
2. 在开发者工具左侧文件树里找到 `cloudfunctions/claimCard` → **右键 → 上传并部署：云端安装依赖**
3. 对 `cloudfunctions/myCards` 做同样的操作

**怎么确认做对了**：云开发控制台的「云函数」列表里能看到 `claimCard` 和 `myCards`，状态正常。

## 第 5 步：登记处里的一条记录长什么样

工作台的「发布到小程序」会往 `cards` 集合写这样一条记录（现在还没做，见文末）：

```json
{
  "code": "NZZHXWZX",
  "cardId": "CARD-0001",
  "status": "unclaimed",
  "ownerOpenId": "",
  "claimedAt": null,
  "createdAt": 1758000000000,
  "card": { "cardId": "CARD-0001", "displayId": "CARD #0001", "date": "2026-09-09", "surface": "dark", "content": {...}, "owner": {...}, "qr": {...} },
  "assets": {
    "front": "cloud://xxx/card/CARD-0001/front.webp",
    "back":  "cloud://xxx/card/CARD-0001/back.webp",
    "layers": { "background": "cloud://xxx/...", "subject": "cloud://xxx/..." }
  }
}
```

云函数只认这几个字段：`code` / `ownerOpenId` / `claimedAt` / `card` / `assets`。

## 不靠工作台也能测（强烈建议先测这一步）

在云开发控制台「数据库 → cards → 添加记录」，手动插一条：`code` 填一个用下面命令生成的码，`ownerOpenId` 留空字符串 `""`。

```bash
python tools/claim_code.py            # 打几个合法短码
python tools/claim_code.py --write-mock   # 给示例卡生成本地演示码
```

然后在小程序里输入这个码：

| 操作 | 应该看到 |
|---|---|
| 第一次输入 | 卡片出现，数据库里这条记录的 `ownerOpenId` 被写上你的 openid、`claimedAt` 有值 |
| 同一台手机再输一次 | 直接进卡牌页，**不算第二次导入** |
| 换一个微信号（别人的手机）输同一个码 | 「这张卡已经被领取了（2026.09.11 已被领取）」 |

**这一步通过了，"只能导入一次"才算真的落地。**

## 第 6 步：在工作台发布一张卡，拿到导入码

这一步不需要云开发也能先试（`--dry-run` 会把码写进小程序的"本地演示码"）：

```bash
python tools/publish_to_mp.py --list                      # 看已发出去的码
python tools/publish_to_mp.py CARD-0002 --dry-run         # 本地发布：出码 + 写进本地演示码
python tools/publish_to_mp.py CARD-0002                   # 真发布：上传素材 + 写云数据库记录
python tools/publish_to_mp.py CARD-0002 --count 5         # 一次发 5 个（一批实体卡）
python tools/publish_to_mp.py --status                    # 看谁领了、什么时候领的
```

真发布之前，先在项目根目录建 `mp-secret.json`（照 `mp-secret.example.json` 填）。

> ⚠️ **最容易卡住的一步**：微信的接口要求你的**本机公网 IP** 在小程序后台的白名单里。
> 报错里会直接给出 IP（`errcode=40164`），把它加到
> 「小程序后台 → 开发管理 → 开发设置 → 服务器域名 / IP 白名单」即可。
> 脚本已经把这条错误翻译成人话了。

`mp-secret.json` 里含 AppSecret，**已在 `.gitignore` 里，永不入库**；`publish/` 目录（素材副本 + 台账）同样不入库。
