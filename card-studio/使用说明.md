# 卡片工坊 · 使用说明(不需要懂代码)

## 怎么用
1. 双击 **`启动卡片工坊.bat`**(首次会弹出命令行黑窗, 别关它, 那是服务)
2. 浏览器会自动打开 `http://127.0.0.1:4399`
3. 把图片拖进页面 → 填卡名(可留空) → 点「生成全息卡」
4. 等 1~3 分钟, 页面下方直接预览: 可拖拽旋转、翻面、拉景深/光泽滑块、切换卡面质感
5. 完成后浏览器地址栏的预览页也能单独打开/收藏

> 用完后关掉命令行黑窗即可停止服务。

## 素材建议(决定卡面好看与否)
- 最好: **透明底 PNG**(或已抠好的人物/角色图)
- 其次: 纯白/纯色底图(工具会**保守抠图**, 只去与边角几乎同色的像素, 不误伤浅色衣物)
- 棋盘格底也会自动转透明
- **复杂背景的图(照片/插画背景)**: 工具默认**保留整图、不硬抠**, 全部颜色原样上卡, 两侧衬底
- 页面里可以随时手动指定「自动判断 / 保留整图 / 扣除纯色底」三种处理方式

## 每张卡会产出什么
生成目录: `card-studio\projects\card-xxxx\`
- `web\` —— 可单独打开的网页卡(双击 `web\index.html` 或 `node web\server.mjs`)
- `card.blend` —— 可编辑的 Blender 工程(想改材质/灯光/出渲染图)
- `assets\` —— 主体/背景/线稿/文字四层透明图 + `source.png` 原图
- `card-config.json` —— 文案与参数(可手动改后重跑)

## 怎么交付给客户
1. 在任务列表那行点 **「📦 导出卡牌」**(约 1 分钟;生成中的卡需先等它完成)
2. 完成后出现 **「⬇ 下载卡包」**,得到 `CARD-0001.zip`
3. 卡包内容:
   - `CARD-0001-single.html` —— **自包含单文件,双击即可打开**(不依赖 Node/网络,可直接发客户)
   - `card.json` —— 卡牌数据(Card ID / 日期 / 年龄 / 祝福 / 归属;**可选字段没数据就完全不显示**)
   - `front.png` / `back.png` / `layers/` / `preview/`
   - `showcase/` —— 干净交付页(**无工具栏 / 无滑块 / 无 Debug**;需要本地服务时跑 `node server.mjs`)

## 生成模板(共 6 种)
「② 卡片设置」最上方选模板, 选中后界面只会显示该模板真正会用到的字段:

| 模板 | 说明 | 背景 |
|---|---|---|
| 经典工坊风格 | 原有风格, 可用「背景风格」换底色(宣纸/深空/玄黑烫金/素雅米白) | 可选 |
| Birthday · Celebration | 明亮开心: 纸屑 + 珊瑚色大数字(主力款) | 模板固定 |
| Birthday · Soft | 温柔浪漫: 长渐变融入 + 大留白 | 模板固定 |
| Birthday · Pop | 年轻大胆: 斜切色块 + 蓝色大数字 | 模板固定 |
| Birthday · Night | 高级安静: 纸张印刷质感 + 排版化构图(高级款) | 模板固定 |
| Birthday · Diorama | 立体画框: 大层距 + 暖金箔(备选款) | 模板固定 |

五套 Birthday 模板都会额外产出**静态卡面**(正片/背面/展示图), 素材准备好后约 6 秒即可查看,
不必等 3D 版完成; 也支持已抠好的透明底图(自动做"浮在卡面上 + 投影 + 底边溶解")。

## 生成后改文案(不用重跑 3D)
任务行上点 **「✏️ 改文案」** → 改卡名/年龄/日期/编号/名字/祝福语/系列名/背面描述/二维码链接
→ **保存并重出静态卡面**(约 10 秒,只重画文字层与二维码,不跑 Blender),缩略图与下载链接随即更新。

> 注意:Night 模板顶部那行**优先用「名字」**,名字留空才用「卡名」。

## 常见问题
- **提示"找不到 Blender"**: 需先保留 `demo-koi` 文件夹(共享其中的 Blender); 或把 Blender 目录放到 `tools\blender-…\`
- **提示"未能自动抠出主体"**: 换透明底 PNG 或纯色底图
- **填了文字却没出现在卡上**: 每个模板用的字段不同, 界面已按模板只列出可用字段(如祝福语目前只有 Night 用)
- **想要更多背景风格/自动编号规则**: 找我调
