图片里的卡片是 `exports/CARD-0001` 和 `exports/CARD-QR01` 的**真实卡面与真实字段**（来自各自的 `card.json`），不是画的假图。

## 已经按反馈落实的

- 页面改成**白底简约**，不再用深色底。
- 去掉"生日""我的收藏"这类**模板字样**：收藏页只写卡号 + 日期。
- 保持**一行两个**。
- 卡牌页的卡牌**静置时轻微浮动**（示意图里用叠影表达）。
- 点击卡片后**放大铺满屏幕**（02 图右下角有三步过渡小样）。
- 卡牌**可以拖动、支持陀螺仪**。
- 页面尽量简单，但**生成卡牌时填的字段保留**（卡号 / 纪念日期 / 寄语等，没填的不出现）。

## 图片呈现不了的东西

静态图无法表现：浮动、转动、翻面动画、层间错位、随视角变化的虹彩与箔片流动、陀螺仪跟随、放大过渡。
这些要在微信开发者工具或手机上才能真正看到——第一版做完后即可扫码体验。

## 重新生成

```bash
python mockups/make_mockups.py
```

脚本只读取 `exports/` 里的预览图、分层素材和 `card.json`，不会改动任何卡片数据。
